# ShopFast Retail - Incident Analysis & Secret Management

## Contexto del Proyecto
ShopFast Retail es una plataforma de comercio electrónico minorista. Una auditoría interna detectó que credenciales críticas utilizadas por el microservicio de inventarios y pasarelas de pago se expusieron accidentalmente en este repositorio durante aproximadamente 72 horas.

## Objetivo de la Actividad
El equipo debe analizar los impactos de esta filtración, evaluar los vectores de exposición, diseñar un plan de respuesta a incidentes inmediato y proponer una arquitectura segura basada en gestión centralizada de secretos.
